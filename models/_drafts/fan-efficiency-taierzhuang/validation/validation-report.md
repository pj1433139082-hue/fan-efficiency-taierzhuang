## 契约与数据质量

### 1. 契约

| 方向 | 字段 | 类型 | 单位 | 含义 |
|---|---|---|---|---|
| 输入 | `inlet_flow` | number | m3/min | 进口风量（面板读数，工况） |
| 输入 | `outlet_pressure` | number | kPa | 出口压力（表压，即背压 Δp） |
| 输入 | `motor_power` | number | kW | 电机输入功率 |
| 输入 | `inlet_temperature` | number | C | 进口温度 |
| 输入 | `elevation` | number | m | 设计海拔（换算当地大气压） |
| 输出 | `eta_excel` | number | 1 | Excel 口径效率，**本期平台生效字段** |
| 输出 | `eta_corrected` | number | 1 | 修正口径效率，并列输出、仅用于对账 |
| 输出 | `wp_excel` | number | kW | Excel 口径气动功率 |
| 输出 | `wp_corrected` | number | kW | 修正口径气动功率 |

两口径共用压比项 `Π = (P入口 + Δp) / P入口`，`K = 0.2857`；差异只在前导项：
Excel 用 `C18 × Q标准`，修正用 `P入口 × Q入口`，两者比值恒为 `T入口 / T标准`。

### 3. 数据质量（摘要，完整证据见 `docs/数据质量对抗性审查.md`）

- **采样节奏**：二污 3,067,402 个时间戳，重复率 0.0000%；间隔 p1 / p50 / p99 = 14 / 15 / 15 秒，>60 s 仅占 0.002%。结论：分钟窗口必须按时间戳切，不能按行数切。
- **量程过滤丢弃比例**（行级判定的副作用，非逐列清洗）：`V_IF` 1.666%、`V_OP` 0.634%、`V_P` 0.626%、`V_ITIT` 1.699%、`V_MTIT` 1.747%。
- **坏值成块，且同厂多机同时出现**（采集侧事件，不是单台传感器故障）：二污三台 2025-04-30 16:00 → 05-14 08:47（328.8 h，期间 `V_ITIT` 读到 241~264 ℃）；一污 6# 2026-09-17 → 10-12（600.1 h，`V_IF` 单调递增到 1.59×10⁶）；六台 2026-02-07 → 02-08（24.4 h）。三段均由 `DATA_OUTAGE` 整段剔除，未做插值。
- **停机是主要状态而非异常**：二污 1# 停机分钟占 90.6%、2# 63.2%、3# 61.7%，一污 6# 84.8%。停机时 `V_IF≈0 / V_OP≈0 / V_P≈0` 是合法读数，必须走 `STOPPED` 而不是当缺失剔除。

### 6. 物理自检

| 自检 | 方法 | 结果 |
|---|---|---|
| 量纲闭合 | `kPa × m³/min ÷ 60 = kJ/s = kW` | 通过（`wp_corrected` 单位 kW，无需额外除 1000） |
| 方向合理 | 令 `Δp = 0` → `Π = 1` → 方括号 = 0 | 通过（功率 0，效率置空标记 `RATIO_INVALID`） |
| Excel 口径是 20 ℃ 特例 | 固定 Q/Δp/P，令 T = 20 ℃ | 通过：两口径差 −0.0056%（残差来自 `C18` 只保留到 `J15` 平均值） |
| 温度方向 | T = 5 ℃ / 30 ℃ | 通过：+5.39% / −3.30%，符号与物理一致 |
| 停机不崩 | `V_P = 0` 直接调用 `compute_row` | 通过：返回 `STOPPED` + 空效率（本条为验证中发现的缺陷，见 §9） |
| 缺输入置空 | `inlet_flow = NaN` | 通过：四字段全空 + `OUT_OF_RANGE`，不补零 |

### 9. 验证边界 —— 本报告没有证明什么

以下四项**没有**现场确认，本报告的一切数字都建立在当前假设之上：

| 参数 | 当前假设 | 若假设不成立的后果 |
|---|---|---|
| `V_P` 的功率口径 | 电机输入功率 | 若为轴功率，效率 **+5.26%**；若为变频器输出，**+3.09%** |
| `V_OP` 的取压点 | 风机出口（表压） | 若取在曝气支管（低约 3 kPa），效率 **−5.61%** |
| `V_IF` 的流量口径 | 工况 m³/min（非热式） | 若实为标况，效率 **−2.03%** |
| `V_ITIT` 的测点位置 | 风机进口 | 影响 Excel 口径（本期部署口径）±1% / 3 K |

因此本报告能证明的是**「按当前契约实现正确、可复现、两口径差异符合推导」**，
不能证明**「线上输出的数值在物理上就是真实效率」**。后者需要现场答复后按契约升级处理，
不在 `built → validated` 的门禁范围内（在线验收回执见 ⑧发布准备）。

验证过程中发现并修复一处缺陷：`compute_row` 在 `motor_power = 0`（停机合法读数）时抛
`ZeroDivisionError`。已加停机短路分支（效率置空、标记 `STOPPED`、气动功率照算），
并补测试 `test_compute_row_with_zero_power_does_not_crash`。修前 22 项测试全过（补上本条后为 23 项），说明原测试集只覆盖了 `predict` 路径，未覆盖 `compute_row` 直调。

- **曲线形态符合工艺预期**：进口温度呈明显季节+日内双周期（一污 4# 从 1 月约 1 ℃ 升到 7 月约 40 ℃），风量与功率同向变化，出口压力稳定在管网背压附近，没有出现「风量为 0 而功率不为 0」的伪运行段。
