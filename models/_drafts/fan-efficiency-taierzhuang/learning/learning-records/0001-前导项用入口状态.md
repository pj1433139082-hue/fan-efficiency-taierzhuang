# 前导项用「入口」状态，不是出口

用户在学完第 1 课后自己提出了修复方案：「那如果要修复就是要用**出口**的 PQ 是么」——**这是一个误解**：出口只出现在压比项 `(P出口/P入口)` 里，前导项要的是**起点**（入口）的状态。已用三种选法的实算对照纠正（入口 63.43 kW / 87.6%；标准 62.41 kW / 86.2%；出口 70.78 kW / 97.8%），并给了通用自检习惯：算出的效率先跟设备正常区间对一眼。

**Implications**：说明「状态配对」这个概念只是**听懂了**，还没内化。第 2 课之前应再验证一次"起点 vs 涨幅"的区分（例如给一条新公式，让他指出每个量属于哪个位置）。同时这也提示：**"账对了但配对错了"是这类公式最隐蔽的错法**，值得在模型契约里做成显式校验。
