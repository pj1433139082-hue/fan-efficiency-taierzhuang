## 三、根因

### 3.1 一句话

**公式里出现三个压力，只有两个是真的。**

| 符号 | 值 | 出处 | 性质 |
|---|---|---|---|
| **P入口** | 100.898 kPa | `C9` | 空气真实进入风机的绝对压力 |
| **P出口** | 148.098 kPa | = P入口 + 背压 47.2 kPa（`C7`） | 真实压力 |
| **P标准** | 101.325 kPa | `L4` | **人为规定的记账基准**，不对应任何真实位置 |

- 压缩功的物理定义要求前导项用 **P入口 × 实测进风量**；
- 表里实际用的是 **P标准 × 标况风量**（`C18 × C6`）；
- 而**压比项 `(P出口 / P入口)` 用的是两个真实压力，是正确的**。

> **准确表述：半实际、半标准——压比对，前导错。**

### 3.2 为什么会差

由理想气体关系可推出 `P × Q = 质量流量 × R × 温度`：**前导项本质上只由温度决定**。

用"标准状态"那一对，等于**假设进气温度是 20℃**；示例值是 **24.8℃**（台儿庄现场实测：一污 4# 25.5℃、5# 25.8℃、二污 2# 26.0℃）。

```
T入口 / T标准 = 297.95 / 293.15 = 1.016374   →   偏低 1.61%（相对）
```

### 3.3 为什么难发现

`C18`（= 354635.5）是从"密度 × 温度"绕道推出来的，而"密度 × 温度"在 1 个大气压下恒等于"压力 ÷ R"，**看起来像一个物理常数**；表里 `D18` 备注也写着"温度 T × 密度 ρ 基本等于常数"。

实际上：

```
C18 = J15 × R / K = (P标准 / R) × R / K = P标准 / K
```

**它携带的唯一信息就是"1 个标准大气压"**，与温度无关（`J = T × ρ = T × P/(R·T) = P/R`，T 被精确约掉）。

## 五、解决办法

### 推荐方案：把"当地压力"显式写进公式，不再藏进共享常数

**① `风机效率核算工具`！`C20`**

```
原： (C18*C6/60*(C19^C14-1))/1000
改： (C9/C14)*(L8/60)*(C19^C14-1)
```

> `C9` = 当地大气压（kPa），`L8` = 实测入口风量（m³/min）。
> `kPa × m³/s = kW`，故不再需要 `/1000`。

**② `5、空气系统`！`T13:T18`**

把前导项的 `C18` 改为当地大气压 `Q13`，风量用实测 `L13`：

```
改： (Q13/$C$14)*(L13/60)*(((M13+Q13)/Q13)^$C$14-1)/N13
```

**③ `5、空气系统`！`I13:I18`**

- 若保留"铭牌额定值"含义：**保持海平面 101.325 不改**，但**必须加注"海平面额定"**，且不与 T 列直接比较；
- 若要与 T 列可比：压比同样改为当地压力。

### 备选方案：保留标况流量写法

前导项乘一个温度补偿因子，即 `C20` 上乘 `L9/L6`（= T入口 / T标准）。

> 两方案本质相同。**推荐前者**——更少歧义，不必引入温度因子。

## 附：一句话给会议的口径

> 这张表的压比算对了，但前导项用的是"标准大气压 × 标况风量"，而压缩功要的是"当地大气压 × 实测风量"，两者差一个 `T入口/T标准 = 1.0164`。结果是**风机电耗被低估、效率被低估 1.4 个百分点**。改法就一行：把前导项换成 `当地大气压 ÷ K × 实测风量`。**表里的数字都是示例，要改的是公式。**
