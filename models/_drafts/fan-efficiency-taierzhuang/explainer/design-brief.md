# Design Brief · 风机效率公式口径讲解（可视化 HTML）

> 任务来源：用户 m00354「现在你用 /design-consult 给我把这个 excel 公式的问题做一个可视化的 html 讲解」
> 运行时：单文件夹静态页面，无构建、无外部依赖，可离线双击打开。
> 证据基线：`风机效率核算工具-公式口径问题汇总.md`、`风机效率核算公式-参数厂家核对清单.md`、`C:\Users\14331\Desktop\枣庄台儿庄自控信号.xlsx`（openpyxl 逐字核对）、`.venv-311` 实算。

## 1. 目标与非目标

**目标**：让一个不懂热力学的现场人员，在 5 分钟内看懂「Excel 风机效率公式哪里错了、错多少、为什么错」，并且能自己拖滑块复算一遍。

**成功判据**
1. 不看讲解文字，只靠页面就能说出「Excel 低估」还是「高估」，并在拖动温度滑块时看到偏差**变号**。
2. 能指出错在「前导项的状态配对」，而不是「压比算错了」。
3. 能当场用一行公式说明怎么修（`C18→C9`、`C6→L8`，两处同时改）。
4. 台儿庄三台在跑风机的实测效率可以当场核对。

**非目标**：不解释多变压缩的热力学推导全过程（只给结果与量纲自检）；不做模型契约/发布；不覆盖曝气器配置数量块；不替代汇报稿 `.md`。

## 2. 受众与使用场景

| 场景 | 读者 | 对版面的要求 |
|---|---|---|
| 主会 / 厂家讲解（投影，边走边讲） | 厂领导、风机厂家技术员 | 单屏信息密度可调，关键数字要大，能停下来说一句就翻页 |
| 会后自读 / 留档 | 现场工程师 | 线性可读，步骤编号清楚，公式可复制 |
| 现场核对 | 值班人员 | 表格式对照，读数与结果并排 |

## 3. 已确认的品味约束（Phase 2.25 展示库选源，用户逐项确认）

| 维度 | 选择 | 依据 |
|---|---|---|
| 字体 | **宋体标题 + 黑体正文** | 用户选定「宋体标题+黑体正文（推荐）」：字号对比拉得开，最像研究报告/审计底稿 |
| 背景 | **纯纸白 + 极细网格** | 用户选定「纯纸白 + 极细网格（推荐）」：投影干净，网格帮读者横向对齐数字 |
| 组件性格 | **直角 + 细线 + 编号标注** | 用户选定「直角 + 细线 + 编号标注（推荐）」：像工程底稿/审计报告，与"证据等级/可当场复核"一致 |

其余五维（动效、布局、媒体）由三版各自拉开，见下表。

**字体落地说明（诚实标注）**：不引 CDN。用系统字体栈 —— 标题 `'Songti SC','Noto Serif SC','SimSun',serif`，正文 `'PingFang SC','Microsoft YaHei','Noto Sans SC',sans-serif`，数字与公式 `'SF Mono','Cascadia Mono',Consolas,monospace`。理由：现场投影可能无网，离线必须可打开；代价是不同机器字重略有差异。

## 4. A / B / C 三个来源方案

三版**共用同一份内容与同一份数值**（同一组读数、同一组表格、同一个试算滑块），只在**布局与信息层级**上拉开。

### A / SAFE —「分步教材」

- **Memorable thing**：一条竖直的编号轨 `01 → 05`，每一步右边挂一条窄旁注「这一步在算什么」；读者沿一条线往下走，不会分叉。
- **审美关键词**：教科书、审计底稿、克制、可复制
- **配色**：纸白底 + 墨黑正文 + 朱红十字（Excel 值）与深绿（正确值）双色编码，仅两处强调色
- **内容节奏**：结论条（3 个数字）→ 五步 → 四种搭配矩阵 → 温度偏差表 → 台儿庄实测 → 修复公式 → 证据等级
- **五维来源指纹**
  | 维度 | 来源 |
  |---|---|
  | 字体 | 宋体标题 / 黑体正文 / 等宽数字（系统栈） |
  | 组件 | 展示库 `component-proof-strip`（可信度证据条）→ 改写为「证据等级」条；编号轨为原创 |
  | 动效 | `quiet-reveal` 克制淡入（每步进入时 8px 上移 + 透明度） |
  | 设计参考 | 展示库 `typography-editorial-scale`（编辑式中英混排字阶） |
  | 排版 | 单列 780px 居中 + 右侧 160px 旁注轨 |
- **风险**：翻页多，投影讲解时要滚很久；对比不够"抓眼"。

### B / BALANCED —「分屏工作台」

- **Memorable thing**：左侧常驻试算台 —— 滚动到任何一步，左边的大数字和两个滑块都在；讲完一步就能立刻拖一下验证。
- **审美关键词**：工作台、双栏、实时、手上有数
- **配色**：同 A，但左侧面板反相（墨黑底 + 纸白字），形成"屏幕里的一块仪表"对比
- **内容节奏**：左 38% 常驻面板（结论 + 滑块 + 实时 η 对比 + 偏差条）；右 62% 滚动（五步 + 表格）
- **五维来源指纹**
  | 维度 | 来源 |
  |---|---|
  | 字体 | 宋体标题 / 黑体正文；左侧数字用等宽大字号 |
  | 组件 | 展示库 `component-state-stack`（状态优先任务条）→ 改写为「口径切换/实时状态」条 |
  | 动效 | `stagger-grid` 证据格依次进入（右侧表格行 24ms 递进） |
  | 设计参考 | 展示库 `hero-split-evidence`（叙事/证据分屏） |
  | 排版 | 固定 38% / 滚动 62% 非对称双栏；移动端折叠为"面板在上、正文在下" |
- **风险**：左侧面板占掉三分一屏，投影时右侧公式会变小；讲解节奏被固定在"左看数、右讲理"。

### C / RISK —「证据地图册」

- **Memorable thing**：首屏是一张非线性的证据拼版 —— 四种搭配矩阵、温度偏差曲线、三个压力同时可见，读完首屏就已经知道结论；详细五步降级为页尾可展开的折叠块。
- **审美关键词**：地图册、拼版、一眼看全、可跳读
- **配色**：同 A，但用极细网格作为版面骨骼（网格线显式可见，单元格对齐网格）
- **内容节奏**：首屏 6 格 bento（结论 / 三压力 / 四搭配 / 偏差曲线 / 试算 / 台儿庄三台）→ 修复公式 → 折叠的五步推导 → 证据等级
- **五维来源指纹**
  | 维度 | 来源 |
  |---|---|
  | 字体 | 同 A，但标注性文字统一 11px 等宽、加字距，作"图注" |
  | 组件 | 展示库 `section-bento-evidence`（非等宽证据拼版）→ 改为 6 格数据拼版 |
  | 动效 | `progressive-unmask` 章节逐层揭示（clip-path 从上往下揭示，每格错峰） |
  | 设计参考 | 展示库 `direction-field-atlas`（整页方向：数据地图册）+ `background-contour-paper` 的网格做法 |
  | 排版 | 12 列网格 + 非等宽格位（4/3/2 跨列混排） |
- **风险（写清代价）**：现场一步步讲会跳，老人第一次看需要自己找路径；窄屏（<900px）拼版塌成单列后备忘感全失；折叠块容易被跳过，等于把推导藏起来。

**三版差异自检**：布局（单列 / 非对称双栏 / 12 列拼版）、信息层级（线性 / 线性+常驻面板 / 非线性一眼看全）、动效（淡入 / 递进 / 揭示）、组件（编号轨 / 状态条 / 图注格）、排版（780px 居中 / 38-62 分屏 / 12 列网格）—— 五维中五维不同，不是只换色或字体。

## 5. 共享内容契约（三版必须完全一致）

| 项 | 值 |
|---|---|
| 读数 | P_in 72.4 kW、Δp 47.2 kPa、H 38.5 m、Q入口 93 m³/min、t入口 24.8 ℃ |
| 三压力 | P入口 100.898 kPa、P出口 148.098 kPa、P标准 101.325 kPa |
| 压比 | Π 1.46780、K 0.2857、Π^K 1.115878、方括号 0.115878 |
| 结果 | Excel 62.406 kW / 86.20%；正确 63.431 kW / 87.61% |
| 偏差 | 页内统一显示「约 1.6%」；精确三个分母：kW 实算 1.62% / 纯温度比 1.61%（汇报稿用这个）/ 反向 1.64% |
| 四种搭配 | 仅「P入口 × Q入口」正确，其余三行均给出等效假设温度 |
| 台儿庄 | 一污 4#/5#、二污 2# 三台在跑，6#/二污 1#/二污 3# 停机 |
| 修复 | `=(C9/C14)*(L8/60)*(C19^C14-1)`，两处同时改 |
| 证据等级 | 读出（openpyxl 逐字）/ 推算（C18 反推压力、出口状态、台儿庄海拔假设） |

## 6. 响应式与可访问性边界

- 断点：`1280px`（宽屏满幅）、`900px`（B 版分屏塌为上下）、`640px`（全部单列，表格改为两列卡片）。
- 正文对比度 ≥ 4.5:1（实际：正文 `#24272c` on `#fbfaf7` ≈ 14:1；次要文字 `#616872` ≈ 5.1:1；朱红 `#a83a20` ≈ 5.9:1；深绿 `#17624a` ≈ 6.7:1）。
- 滑块：原生 `input[type=range]`，带 `aria-label` 与 `aria-live` 数值播报，键盘可操作。
- 动效：`prefers-reduced-motion: reduce` 时全部关闭位移与揭示，仅保留状态变化。
- 所有数字用 `font-variant-numeric: tabular-nums`，避免拖动时抖动。

## 7. 验收条件（交给验证阶段）

1. `?variant=A|B|C` 三版都能在浏览器真实渲染，底部切换器可点、`←`/`→` 可切、URL 同步。
2. 三版共用同一份数据：默认状态下三处结果都必须显示 62.406 / 63.431 / −1.6%，且偏差显示精度全页统一为 0.1 个百分点。
3. 拖动温度滑块到 5 ℃ 与 30 ℃，偏差必须分别显示为正（高估）与负（低估）——这是本页的核心教学点。
4. 桌面（1440×900）与移动（390×844）均无横向滚动条、无重叠。
5. 控制台零 error。
6. `prefers-reduced-motion` 下无位移动画。
7. 每版底部"来源指纹"面板能列出上表五维来源。
