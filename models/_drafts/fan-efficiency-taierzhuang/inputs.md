# 输入清单（开工三件套之一）

> 纪律：**每一条被取用的输入都必须在这里登记，并标明来源**。
> `来源` 只允许三个值：
> `真实`＝现场/平台真数据；`示例`＝文档或旧表里的示范数据，**不得当口径用**；
> `待确认`＝还没跟厂端/业主核对。
> 用 `示例` 数据算出来的结论只能写成"机制验证"，不得写成模型口径。

| 输入 | 类型/单位 | 来源 | 说明 |
| --- | --- | --- | --- |
| inlet_flow（进口风量，`V_IF`） | number / m3/min | 真实 | IoT 直连拉取 2025-05-01→2026-10-16，4,646,311 行 15 s 数据（二污 17.5 个月、一污 9 个月）。工况流量，厂家面板换算值（2026-10-18 确认），不是流量计直测 |
| outlet_pressure（出口压力，`V_OP`） | number / kPa | 真实 | 同上拉取。表压、取压点在风机内部蜗壳出口（2026-10-18 确认） |
| motor_power（电机输入功率，`V_P`） | number / kW | 真实 | 同上拉取。电机输入功率且含全部损耗（2026-10-18 确认）→ 算出的是机组效率，不是风机本体效率 |
| inlet_temperature（进口温度，`V_ITIT`） | number / degC | 真实 | 同上拉取。只影响 Excel 口径（每 3 K 约 ±1.0%），修正口径里它已含在 P·Q 中 |
| elevation（设计海拔） | number / m | 真实 | 竣工图设计海拔 38.5 m（一污/二污同值），换算进口绝压 100.898 kPa；0~50 m 对效率影响 <0.1 个百分点 |
| 停机判据（`S_RUN`） | — | 真实 | 台账 `S_RUN` 可用，但清洗后判据统一为 `V_P>5 kW`（对 S_RUN 缺测段更稳） |
| 设备铭牌（额定风量/升压/功率/效率） | — | 待确认 | 组合模型需要每台 `q_min/q_max` 与额定工况，待厂家给铭牌（E-1） |
| 喘振最小允许风量 | — | 待确认 | 决定推荐风量能否执行，待厂家（E-3） |
| 厂家风量范围（允许运行区间） | — | 待确认 | 历史实测区间不等于厂家允许区间，待厂家（A-2） |
| 温度探头安装位置 | — | 待确认 | 影响 `T入口/T标准` 修正是否成立，待厂家（C-4） |

## 待确认（要跟厂端核对）

- [ ] C-4 进口温度探头装在进气管、机房环境还是机壳表面
- [ ] E-3 喘振报警对应的最小允许风量、保护动作方式
- [ ] A-2 厂家样本允许的风量范围（用于划有效区间）
- [ ] E-1 每台铭牌：型号、额定风量（注明工况/标况）、额定升压、额定轴功率、电机功率、转速
- [ ] E-2 是否有性能曲线或出厂试验报告
