# 台儿庄曝气风机效率核算模型 · 试跑包（v0.1.0）

零第三方依赖，只要 Python 3.11 及以上。**不需要装任何库**（只有第三个演示要 pandas）。

## 三步跑起来

```
cd fan-efficiency-demo
python demo_1_single.py      ← 先跑这个，10 秒出结果
python demo_2_batch.py       ← 读一天的 15 秒原始数据，出整天的效率统计
python tests/test_model.py   ← 23 项自测（需要 pandas：pip install pandas）
```

Windows 上如果 `python` 不在 PATH，用你自己的解释器路径，比如
`"C:\Program Files\Python311\python.exe" demo_1_single.py`。

## 演示一：5 个读数算效率

输入是四类现场读数 + 一个常数：

| 输入 | 含义 | 单位 |
|---|---|---|
| 电机功率 | 风机面板上的总功率 | kW |
| 进口风量 | 风机面板流量 | m3/min |
| 出口压力 | 风机出口背压 | kPa |
| 进口温度 | 进气管温度 | ℃ |
| 海拔 | 竣工图设计海拔，台儿庄 38.5 | m |

输出两个效率，**这一版两个都算、并列输出**：

| 口径 | 前导项用哪个状态 | 说明 |
|---|---|---|
| Excel 口径 | 标准状态（1 atm、20 ℃） | **本期平台部署读这个**，跟现场一直用的模板一致 |
| 修正口径 | 真实进口状态 | 物理上正确的那个，用于对账 |

模板上那组示例读数（72.4 kW / 93 m3/min / 47.2 kPa / 24.8 ℃ / 38.5 m）应当得到：

```
Excel 口径   62.406 kW   86.20%
修正口径     63.431 kW   87.61%
```

差 1.6%，来源是「进口温度不是 20 ℃」。这个差随季节变号：20 ℃ 时为零，冬天约 +5%，夏天约 −5%。

也可以直接喂自己的数：

```
python demo_1_single.py 42.2 46.1 46.2 25.5
```

四个数依次是 功率kW、风量m3/min、出口压力kPa、进口温度℃。

## 演示二：跑一整天

`sample-data.csv` 是二污 2# 在 2026-09-19 的真实 15 秒数据（5760 行）。脚本会：

1. 按**时间戳**切分钟（不是按行数切）；
2. 每个分钟做有效性判定（越界、停机、缺样本分别打标记）；
3. 对有效分钟算双口径效率；
4. 打印质量标记分布和效率统计。

脚本里 `ELEV = 38.5` 是海拔，改它就能看海拔影响（实测 0~50 m 对效率影响 <0.1 个百分点）。

CSV 需要的列：`data_time_bj, V_IF, V_OP, V_P, V_ITIT, S_RUN`，
单位 m3/min、kPa、kW、℃、0/1。

## 演示三：下游接入

`demo_3_predict.py` 演示契约入口 `model.predict()`：传一个表，返回
`eta_excel / eta_corrected / wp_excel / wp_corrected / quality` 五列。
无效行四个数是 NaN，`quality` 说明原因（`STOPPED` 停机 / `ROW_INVALID` 越界 /
`NO_SAMPLE` 样本不足 / `DATA_OUTAGE` 数据中断 / `RATIO_INVALID` 压比异常）。

这个演示需要 `pip install pandas`。

## 公式

```
气动功率 W = (1/K) × P进口 × Q进口 × [ (P出口/P进口)^K − 1 ]
风机效率 η = W / 电机输入功率
K = 0.2857（空气 (k−1)/k，k=1.4）
```

两个口径**共用同一个压比项**，只差前导项 `P×Q` 用的是哪个状态：

- Excel 口径：（标准大气压 ÷ K × 标准风量），标准风量由进口风量按
  `Q标准 = Q进口 × (P进口/P标准) × (T标准/T进口)` 折算；
- 修正口径：直接用进口压力 × 进口风量。

两者之比恰好等于 `T进口/T标准`。这也是为什么 Excel 口径在 20 ℃ 时没有问题。

## 这一版还没定的四件事

这四项需要厂家答复，答复前不影响算法跑通，但会影响数值的**绝对值**：

1. **功率口径**：`V_P` 是电机输入功率、变频器输出，还是轴功率？如果是轴功率，效率要低 5% 左右。
2. **出口压力**：`V_OP` 是表压还是绝压？取压点在蜗壳出口还是止回阀后？差 2~3 kPa 会让效率差 3.7%~5.6%。
3. **风量口径**：`V_IF` 是工况流量还是已折算的标况？若是标况，要换回去，差 2%。
4. **温度测点**：探头在进气管里还是机房环境？只影响 Excel 口径（每 3 ℃ 约 1 个百分点）。
